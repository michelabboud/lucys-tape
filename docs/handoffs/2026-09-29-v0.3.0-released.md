## Gotchas

- `hexe run --session resume` cannot resume a codex review (no sandbox flag on `codex exec
  resume`) and still exits 0: start a new session key and check the output, not the exit code.
- A codex review lane cannot open sockets: the viewer's HTTP tests fail there; run them here.
- `os.replace` is never in `os.supports_dir_fd`; check `os.rename` (see `tools/safe_paths.py`).
